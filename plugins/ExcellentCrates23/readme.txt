This configuration includes 6 fully-custom crates, perfect for survival or RPG servers.

--------------------
📦 INCLUDED CRATES:
--------------------
- Common (Yellow)
- Uncommon (Gray)
- Rare (Blue)
- Elite (Green)
- Legendary (Gold)
- Insane (Red)

--------------------
🛠 INSTALLATION:
--------------------
1. Stop your Minecraft server.
2. Navigate to: /plugins/ExcellentCrates/
3. BACKUP your current files (optional but recommended).
4. Replace your crates,key, and config.yml files with the ones from this pack.
5. Start your server again.
6. Run the command: /crates reload
7. Place your crate blocks and assign crate types as needed.

✅ You’re ready!
